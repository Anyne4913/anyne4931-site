# APS-4001 页面图标映射

来源：Lucide 官方图标库（https://lucide.dev），保留 SVG 的 `currentColor` 描边，以便页面统一使用参考图的亮蓝色。

- `advantages/`：自动化、高速量产、高精度视觉定位、多种供料方式。
- `process/`：供料、视觉识别、精准取放、并行烧录、结果判定、自动收料。
- `capabilities/`：支持多种封装、双重防叠料保障、高速稳定运行、自动生成追溯报表、高精度场景、维护便捷。
- `header/`：搜索与地球图标。骨架阶段仅保留对应图标占位，视觉精修阶段再调用实际 SVG。

建议实现：图标容器使用 `color: #009FE3`，桌面端保持统一的 `stroke-width: 2` 视觉重量；SVG 自身已使用这一线性描边规范。
